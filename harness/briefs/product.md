# 产品摘要

本文以 `hanzi.md` 和后续已确认决策为来源，记录当前可验证产品基线。

## 产品目标

字有方面向小学生家庭练字场景，通过微信小程序完成拍照上传、逐字识别、错字纠错、书写纠偏和重复练习，帮助学生依据清晰、可追溯的建议自主改进。

## 用户与参与关系

- 学生：选择目标文字、拍照上传、查看逐字结果、重新练习和提交结果反馈。
- 监护人：完成首次数据处理确认，并在生成脱敏结果分享卡前再次确认。
- 产品与算法运营人员不在 MVP 前台用户范围内；教师、班级和教务能力不纳入 MVP。

## 核心能力

| 编号 | 能力 | 预期业务结果 |
| --- | --- | --- |
| CAP-00 | 微信身份与监护人确认 | 未完成授权时不上传或持久化未成年人练字图片 |
| CAP-01 | 多字图片提交 | 支持拍照/相册、目标文字、离线待提交、续传和重拍 |
| CAP-02 | 文字识别 | 切分多个方格，输出逐字 OCR、位置、置信度和不确定状态 |
| CAP-03 | 错字纠错 | 依据重复 OCR、目标文本和结构证据区分错字与不确定结果 |
| CAP-04 | 字形五维评价 | 参考标准宋体，评价笔画规范、间架结构、字形比例、位置布局和稳定性 |
| CAP-05 | 大模型建议 | 只解释已有证据，生成低龄学生可理解的纠错/纠偏步骤 |
| CAP-06 | 问题字本 | 在“我的”中沉淀错字和待纠偏字，支持再次练习 |
| CAP-07 | 矫正进度 | 保留同一问题字的历次有效结果和版本差异 |
| CAP-08 | 结果反馈 | 学生可发起重新评测，原结果和反馈保持可追溯 |
| CAP-09 | 受控分享 | 监护人确认后生成不含原图的脱敏结果卡 |
| CAP-10 | 成长曲线与重点字库 | 三次及以上有效练习后展示可比评分趋势，并持续监测低分或不稳定汉字 |

## 核心闭环

目标文字 → 拍照/相册 → 本地待提交或私有上传 → 图片质量与方格切分 → OCR 识别 → 错字纠错 → 字形纠偏 → 模型解释建议 → 问题字本 → 再次练习。

## 已确认体验基线

- 手机底部导航只有“练习—中间拍照—我的”。
- “字本”位于“我的”内作为二级菜单。
- 多字结果以“主对比视图＋横向单字列表＋问题清单”展示。
- 单字详情同时展示五项字形评价；稳定性在同一字积累三次可比练习后生效。
- “字本”增加“重点字库”筛选，集中展示近三次均分或稳定性持续偏低的字。
- 视觉采用纸白、朱红、墨黑，缩小 Logo，优先保证内容和交互面积。
- 不出现教师复核、人工审核、周期报告、排行、积分或挑战。

## 仍受门禁控制

- `mobile-v2` 可点击高保真原型及联合评审。
- 监护人确认的法律文案、撤回方式和适用年龄规则。
- 标准宋体字形、示例图片及评测样本的许可证。
- 生产 OCR/评分阈值、准确率、时延和成本目标。
- 腾讯云第三方处理、数据地域、保留和删除证据。
