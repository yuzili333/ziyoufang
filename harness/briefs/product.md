# 产品摘要

本文是对 `hanzi.md` 的可验证摘要，不替代原始文档，也不补充未经确认的产品或技术决策。

## 产品目标

字有方面向小学生汉字书写练习场景，通过自动识别、质量评价和针对性矫正，帮助学生自主发现错字与书写不美观问题，形成可持续跟踪的改进闭环。

## 主要用户与场景

- 学生：上传书写练习、自助测评、查看问题并反复矫正。
- 家庭学习参与者：辅助学生在家庭场景完成练习与跟踪。

MVP 不包含教师复核、教师端工作流和教务能力；监护人的账户、授权和查看范围后续确认。

## 核心能力

| 编号 | 能力 | 预期业务结果 |
| --- | --- | --- |
| CAP-01 | 自动汉字识别 | 从学生上传的书写图片中识别汉字 |
| CAP-02 | 书写质量评估与打分 | 参考标准宋体字形，对书写质量进行量化评价 |
| CAP-03 | 不美观字识别 | 定位笔画、偏旁、部首等结构问题并给出问题清单 |
| CAP-04 | 错字识别 | 识别错误汉字并说明主要结构问题 |
| CAP-05 | 笔画对比 | 展示手写字与模板字的差异，帮助理解问题 |
| CAP-06 | 问题字本 | 沉淀错字和不美观字，支持针对性练习 |
| CAP-07 | 矫正进度跟踪 | 记录同一问题字的重复练习、历次结果和当前矫正状态 |

## 核心闭环

学生拍照上传 → 系统识别与评估 → 生成错字/不美观字清单 → 展示差异与问题 → 学生依据模型建议针对性练习 → 系统持续记录矫正过程。

## 待原型或技术选型确认

- 图片上传限制、拍摄引导、批量处理和失败恢复方式。
- 单字切分、学生结果反馈和重新评测交互。
- 分数维度、分值范围、等级、阈值及解释方式。
- “错字”与“不美观字”同时发生时的归类规则。
- 标准宋体字库、笔顺和字形数据的来源与授权。
- 学生与家庭参与者的账户、授权和数据关系。
- 未成年人数据、书写图片和模型调用的隐私合规要求。
