# mobile-v2 全量状态矩阵

## 全局与身份

| 状态 | 触发 | 页面表现 | 允许操作 | 禁止副作用 |
| --- | --- | --- | --- | --- |
| 首次进入 | 无本地授权记录 | P-00 品牌与开始按钮 | 查看说明、开始 | 不创建云端主体数据 |
| 待隐私授权 | 准备调用相机/相册/上传 | P-01 分层告知 | 同意、拒绝 | 未同意不读取或上传图片 |
| 待监护人确认 | 已阅读但未确认 | P-01 确认区 | 确认、返回 | 不把勾选阅读视为监护人确认 |
| 已授权 | 授权记录有效 | 进入 P-02/P-03 | 正常练习 | 不重复弹窗干扰每次练习 |
| 已撤回 | 用户撤回 | 阻断新上传并说明影响 | 重新授权、删除数据 | 不继续第三方处理 |

## 拍摄、文件与网络

| 状态 | 触发 | 页面表现 | 恢复动作 |
| --- | --- | --- | --- |
| 相机权限待申请 | 首次拍摄 | 系统授权前置说明 | 同意后打开相机 |
| 相机权限拒绝 | 用户拒绝 | 提供去设置和相册入口 | 设置授权或选相册 |
| 相机不可用 | 宿主/设备不支持 | 明确说明，只保留相册 | 选相册或退出 |
| 已取消拍摄 | 用户取消 | 返回原页面，不生成任务 | 再次拍照 |
| 本地空间不足 | 保存前预检失败 | 显示所需空间和清理入口 | 清理后重试 |
| 离线待提交 | 拍摄完成但无网络 | 保存文件和幂等任务，P-02 显示待提交 | 恢复网络后继续 |
| 上传中 | 已联网并开始上传 | 进度、取消入口 | 完成或取消 |
| 上传超时 | 超时/可重试错误 | 保留本地文件和同一任务 | 使用同一幂等键重试 |
| 上传取消 | 用户二次确认 | 任务为已取消；保留图片处理选项 | 删除或重新创建任务 |

## 图片质量与分析

| 状态 | 结果规则 | 学生可见表现 | 后续 |
| --- | --- | --- | --- |
| 图片合格 | 可定位练字本和方格 | 进入分析 | 切分 |
| 模糊 | 关键笔画不可辨 | 显示放稳手机和改善光线 | 重拍/相册 |
| 过暗/过曝 | 对比度不足 | 指出光线问题 | 重拍/相册 |
| 反光 | 方格局部遮蔽 | 指出反光区域 | 调整角度重拍 |
| 裁切不完整 | 练字本边界缺失 | 提示拍完整页 | 重拍 |
| 无法切格 | 方格结构不可靠 | 不进入确定评价 | 重拍/确认目标内容 |
| 部分可处理 | 仅部分单格有效 | 显示成功/失败/不确定数量 | 确认继续或重拍 |
| 分析中 | 任一分析阶段 | 展示 `progressStage` | 可离开页面 |
| OCR 不可用 | 超时/限流/服务错误 | 任务失败且可重试 | 有界重试 |
| 模型不可用 | 建议接口失败 | 识别/评分保留，展示模板建议 | 后台可重试建议或结束 |
| 部分完成 | 单格失败但存在有效结果 | 显示每格状态与汇总 | 有效结果可入字本 |
| 已取消 | 用户确认取消 | 停止后续阶段 | 返回练习首页 |

## 单字结果

| 分类 | 必要证据 | 分数 | 字本 | 主操作 |
| --- | --- | --- | --- | --- |
| `normal` | 内容一致且质量达标 | 可显示 | 不写入 | 切换下一个字 |
| `wrong` | 两次稳定 OCR 为同一非目标字且对齐明确 | 可显示并说明内容错误优先 | 写入错字筛选 | 对照目标重写 |
| `needs_correction` | 内容一致但确定性质量特征未达标 | 可显示 | 写入待纠偏筛选 | 按建议再练 |
| `uncertain` | 低置信、OCR 冲突或无法对齐 | 不显示伪精确分数 | 不写入 | 重拍、确认目标文字 |
| `failed` | 单格处理失败 | 不显示 | 不写入 | 重拍或稍后重试 |

## 五维评价、成长曲线与重点字库

| 状态 | 触发 | 页面表现 | 数据规则 |
| --- | --- | --- | --- |
| 单次有效评价 | 当前字具有有效分数 | 展示笔画规范、间架结构、字形比例、位置布局 | 分数与评分版本、标准字版本绑定 |
| 样本 1 次 | 仅一次可比练习 | “再练2次开启成长曲线”，稳定性为空 | 不入重点字库 |
| 样本 2 次 | 两次可比练习 | “再练1次开启成长曲线”，稳定性为空 | 不判断趋势，不入重点字库 |
| 成长可用 | 三次及以上可比练习 | 展示总分曲线、五维明细、近三次均分和稳定性 | 只计算最近三次可比分数 |
| 重点监测 | 近三次均分或稳定性低于入库阈值 | 显示“已纳入重点字库”和原因 | POC 入库阈值 70，记录规则版本 |
| 恢复稳定 | 连续三次总分、均分和稳定性均达到退出阈值 | 显示“已恢复稳定” | POC 退出阈值 80，保留历史入库记录 |
| 评分版本变化 | 评分或标准字版本变化 | 曲线断点、不可直接比较提示 | 新分段重新累计三次样本 |

## 反馈、删除与分享

| 状态 | 页面表现 | 数据规则 |
| --- | --- | --- |
| 反馈编辑中 | 原因必选、补充文字选填 | 不修改原结果 |
| 重新评测中 | 原版本保留，新任务显示阶段 | 新任务与原任务关联 |
| 删除待确认 | 列出图片、结果、字本和分享影响 | 未确认不删除 |
| 删除处理中 | 禁用重复提交并展示进度 | 幂等执行 |
| 分享待确认 | 先展示脱敏预览和确认说明 | 不复用首次授权 |
| 分享有效 | 只显示脱敏摘要 | 不暴露私有文件或内部标识 |
| 分享已撤销/过期 | 显示不可访问 | 不影响原始练习结果 |

## 响应式和可访问性

| 状态 | 验收要求 |
| --- | --- |
| 紧凑竖屏 | 底部导航和中央拍照不遮挡内容；单字列表可横向滑动 |
| 紧凑横屏 | 安全区正确；主结果可滚动，无固定高度裁切 |
| 中型 | 结果内容控制行宽，手写/标准字允许并排 |
| 扩展 | 左列表右详情双栏，无空白失衡和内容溢出 |
| 字体放大 | 关键文案换行；按钮高度增长；不截断状态和建议 |
| 长建议 | 最多三条，卡片自然增高，不覆盖底部导航 |
