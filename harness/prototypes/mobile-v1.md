# 字有方移动端原型 V1

## 原型信息

- 版本：`mobile-v1`
- 日期：2026-08-07
- 状态：已确认，作为正式客户端首版页面与交互基线
- 产品端：手机移动端，覆盖 HarmonyOS、Android、iOS；结构预留 PAD
- 视觉方向：设计方案一，练字帖式白、朱红、黑主题

本原型将此前会话中已经确认的视觉方案和三轮调整固化为可追踪规格。它是页面、状态与交互的评审证据；最终像素表现以 ArkUI-X 真机渲染验收为准。

## 全局信息架构

手机底部导航固定为三个入口：

1. **练习**：最近一次多字评测结果、单字切换、对比视图和纠错问题清单。
2. **拍照上传**：位于底部导航中央，使用朱红主按钮，进入应用内引导拍摄。
3. **我的**：本地数据和个人设置；“字本”作为二级菜单放在此页。

不设置“周报”导航，不设置独立“字本”一级导航，不出现教师复核入口或提示。

## 页面与状态

### P-01 练习／多字评测结果

- 顶部使用较小产品 Logo、产品名和本次识别字数，降低品牌区高度。
- 标题下说明“左右滑动浏览识字结果，点选单字查看对比和纠错建议”。
- 单字结果使用可横向滑动的卡片列表，展示目标字、分类和分数；当前字使用朱红描边。
- 主视图同时展示手写字、标准宋体字、分数、问题清单和练习建议。
- “结果有误”位于结果末尾，提交后触发重新评测，不直接修改当前结果。
- 正常、错字、不美观字、待确认分别提供可辨识状态；待确认不得进入问题字本。

### P-02 应用内引导拍摄

- 顶部提供取消和相册入口。
- 取景区显示练字方格对齐辅助线和朱红边界。
- 文案指导学生将整页方格练字本放入框内，保持页面平整、光线均匀。
- 底部主操作为拍照，拍照后进入图片质量检查。
- 权限拒绝、相机不可用、取消拍摄必须返回明确状态，不生成练习任务。

### P-03 图片质量与处理状态

- 合格图片展示保存成功和联网评测进度。
- 离线时保存为“待提交”，允许回到练习页；联网后使用同一任务继续。
- 模糊、过暗、过曝、裁切不完整时展示原因和“重新拍摄／从相册选择”。
- 部分文字可处理时明确显示成功、失败和待确认的单字数量。

### P-04 我的

- 展示本地练习数据说明。
- “字本”作为二级菜单，副标题为“错字、不美观字与历次矫正”。
- 提示数据默认保存在本机，联网评测仅按授权提交必要图片。

### P-05 字本

- 提供错字和不美观字两个筛选，不重复统计同一次练习。
- 每个问题字展示目标字、最近状态、练习次数和最近评测时间。
- 点选问题字进入历次矫正详情，可再次发起针对性拍摄练习。
- 不提供周期报告、教师复核、分享、排行或积分入口。

### P-06 历次矫正与重新评测

- 按评测时间展示同一目标字的全部有效练习，保留退步记录。
- 评价基线版本不同的记录明确标记不可直接比较。
- 学生提交“结果有误”时记录原因与时间，并生成重新评测状态。
- 新结果完成后更新当前字本状态，同时保留原结果版本。

## 核心流程

### 首次练习

拍照上传 → 图片质量检查 → 本地保存 → 联网提交 → 多字识别与评测 → 单字列表 → 对比与问题清单 → 问题字写入字本。

### 离线恢复

拍照上传 → 本地保存为待提交 → 返回练习 → 网络恢复 → 原任务继续上传 → 获取结果；不得创建重复字本记录。

### 纠错练习

我的 → 字本 → 选择问题字 → 查看历次结果 → 发起练习 → 获取新结果 → 更新矫正状态。

### 结果反馈

练习结果 → 选择单字 → 结果有误 → 填写原因 → 重新评测 → 保留原结果并展示新版本。

## 视觉与可用性

- 主色：纸白 `#F7F3EA`、朱红 `#C43A31`、墨黑 `#1D1B19`。
- Logo 在页面头部控制为约 38–48vp，不占用主交互空间。
- 主按钮使用朱红；正文和手写字使用墨黑；辅助文字使用暖灰。
- 触控目标不小于 44vp，核心按钮文案清晰，不依赖图标单独表达。
- 支持系统字体放大、安全区、横竖屏和低龄学生可理解的短句。

## PAD 预留

- compact `<600vp`：底部导航、单栏结果，单字列表横向滑动。
- medium `600–839vp`：页面容器使用 8 栏网格，允许结果区扩展。
- expanded `>=840vp`：页面容器使用 12 栏网格，后续切换为单字列表＋对比详情双栏和侧边导航。
- MVP 不交付手写笔、键鼠快捷键、PAD 专属页面或折叠屏专属交互。
