## 全局信息架构

底部导航仅包含三个入口：

1. **练习**：目标文字、待提交任务、最近评测和结果主工作区。
2. **拍照**：中央朱红主按钮，进入拍照/相册流程；不是独立业务 Tab。
3. **我的**：授权、数据、反馈和设置；“字本”位于此页作为二级菜单。

不出现教师复核、人工审核、周报/月报/季度报/年报、排行榜、积分或挑战。

## 页面清单

### P-00 首次进入

- 小 Logo、产品名“字有方”和短句“汉字有形，习字有方”。
- 解释微信身份只用于进入产品和关联练习，不把微信用户直接宣称为监护人。
- 主操作“开始使用”；次操作“先看看说明”。

### P-01 隐私授权与监护人确认

- 分层说明练字图片用途、OCR/模型第三方处理、私有存储、默认留存和删除方式。
- 独立勾选“我已阅读”，再由监护人执行“同意并继续”。
- “暂不同意”退出上传链路；不创建云端练习任务。
- 授权撤回入口位于“我的—隐私与数据”。

### P-02 练习首页

- 品牌区保持紧凑，把主要空间给目标文字和最近练习。
- 目标文字为必填；支持直接输入和从最近内容再次选择。
- 显示待提交、处理中、最近完成的任务摘要。
- 无历史时通过中央拍照按钮引导首次练习。

### P-03 拍照与相册

- 顶部提供取消和相册入口。
- 取景区显示整页方格对齐边界，指导页面平整、光线均匀、方格完整。
- 拍摄后进入 P-04，不直接提交。
- 权限拒绝时提供“去设置”和“从相册选择”；相机不可用时只保留相册路径。

### P-04 上传确认与质量反馈

- 显示整页预览、目标文字和预估方格数量，允许重拍或换图。
- 联网时“确认上传”；离线时“保存，联网后提交”。
- 模糊、过暗、过曝、反光、裁切不完整和无法定位方格分别提供短句说明。
- 部分可处理时明确成功、失败和不确定数量，由学生确认是否继续。

### P-05 分析进度

- 依次显示“检查图片—切分方格—识别文字—对比字形—生成建议—保存结果”。
- 用户可离开页面，任务在练习首页继续显示；取消必须二次确认。
- 模型建议降级时说明“识别和对比已完成，建议暂用基础提示”，不把任务显示为整体失败。

### P-06 多字评测结果

- 顶部摘要展示总字数、正常、错字、待纠偏、不确定和失败数量。
- 横向单字列表展示目标字、分类和分数；当前字使用朱红描边。
- 主区域同屏展示手写字、思源宋体参考字形、差异标注、分项分数、问题清单和最多三条练习建议。
- 主视图采用第二套方案的“叠加／并排”切换，默认以单一大田字格叠映手写字和朱红标准字差异。
- 五维评分固定展示“笔画规范、间架结构、字形比例、位置布局、稳定性”；不足三次可比练习时稳定性显示“样本积累中”。
- 三次及以上可比练习时展示紧凑成长曲线、最近三次均分和重点字库状态；不同评分/字形版本以断点分段。
- `wrong` 使用“错字”，`needs_correction` 使用“待纠偏”，`uncertain` 使用“还不能确定”，`failed` 使用“这个字没有分析成功”。
- “结果有误”进入 P-09；不确定和失败状态提供重拍/重写入口。

### P-07 我的

- “字本”作为首个二级菜单，副标题“错字、待纠偏字与历次练习”。
- 其他二级入口：隐私与数据、结果反馈记录、关于字有方。
- 只显示结构化学习摘要，不展示周期报告。

### P-08 字本与历次矫正

- 筛选“错字”“待纠偏”“重点字库”；不确定和失败结果不写入。
- 同一主体、同一目标字归集为一个条目，显示最近状态、练习次数和最近时间。
- 详情按时间展示全部有效结果；评分版本不同则显示“评价标准不同，不能直接比较”。
- 主操作“再练一次”，进入针对该字的 P-03。
- 重点字库条目展示入库原因、近三次均分、稳定性、成长方向和入库时间。

### P-09 结果反馈与重新评测

- 原因包括“识别的字不对”“问题说明不符合”“分数明显不合理”“其他”。
- 文本补充为选填并限制长度；提交前说明原结果不会被直接修改。
- 提交后展示新评测任务，完成时并列呈现原版本和新版本。

### P-10 删除与受控分享

- 删除练习前列明将删除的图片、结果、字本关联和分享卡影响。
- 分享前展示脱敏预览，并要求监护人再次确认。
- 分享卡只显示目标字、脱敏评分摘要、问题类别和鼓励性建议；不显示原图、裁剪图、真实姓名、文件地址或内部任务 ID。

### P-11 成长曲线与重点字库详情

- 第一次和第二次可比练习显示“样本积累中”和距离启用成长曲线所需次数，不显示稳定性数值。
- 第三次起按时间展示总分折线；点选记录可查看当次五维评分，默认突出最近三次窗口。
- 显示最近三次均分、稳定性、POC 入库线 `70` 和退出线 `80`，同时明确这些阈值仍待专家和样本校准。
- 低于入库线时显示“已纳入重点字库”和具体原因；达到退出条件时显示“已恢复稳定”，历史曲线和入库记录保留。
- 评分或标准字版本变化时显示曲线断点和“评价标准已更新，前后不能直接比较”。

## 核心可点击流程

### 成功路径

P-00 → P-01 → P-02 输入目标文字 → P-03 拍照 → P-04 确认 → P-05 分析 → P-06 切换多个单字 → P-07 → P-08 再练一次。

### 离线恢复

P-03 → P-04 离线保存 → P-02 待提交卡片 → 模拟联网 → P-05 → P-06；全过程沿用同一任务，不重复写入字本。

### 图片异常

P-03 → P-04 模糊/裁切不完整 → 重拍或相册 → P-04 合格 → P-05。

### 部分完成与模型降级

P-05 → 部分单字失败或建议服务不可用 → P-06 展示已完成结果、失败单格和基础模板建议。

### 反馈、删除和分享

P-06 → P-09 重新评测；P-06 → P-10 分享预览/监护人确认；P-07 → 隐私与数据 → P-10 删除确认。

### 成长与重点监测

P-06 第一次/第二次结果 → 样本积累提示 → 第三次可比结果 → P-11 成长曲线 → 低均分或低稳定性 → P-08 重点字库 → 再练一次 → 达标后退出重点状态但保留历史。

## 视觉和可用性约束

- Logo 高度目标为 32–40px，不挤占结果工作区。
- 纸白作为页面背景；朱红只用于主操作、当前选择和关键差异；正文与手写字使用墨黑。
- 不使用紫蓝渐变、卡通吉祥物、游戏化徽章或密集仪表盘。
- 单字结果沿用选定方案的大田字格叠映主视图；五维评分和成长曲线使用轻量分隔，不堆叠卡片。
- 触控目标不小于 44px；核心按钮同时使用文字和图标，不用图标单独表达。
- 支持系统字体放大、安全区、长文本换行和低龄学生可理解的短句。

## 响应式规则

- 紧凑 `<600px`：单栏、底部导航、横向单字列表，主对比视图在列表下方。
- 中型 `600–839px`：限制正文最大宽度，结果卡可并排展示手写字和标准字。
- 扩展 `>=840px`：切换左侧导航，以“单字主列表＋字形对比工作区＋评价洞察栏”形成主从布局；参考视口、区域宽度和折叠规则以 [`responsive-layout-v2.json`](../contracts/responsive-layout-v2.json) 为准。本轮只验证信息架构和切换逻辑，不实现 PAD 专属功能。

## 原型模拟数据声明

原型使用 `harness/fixtures/` 的合成图片和固定结果。所有识别、评分、阶段耗时、离线恢复、删除和分享行为均为交互模拟，不调用微信云开发、OCR、模型或生产服务，不代表准确率和性能承诺。
