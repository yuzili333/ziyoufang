# 验证结果约定

此目录用于存放 harness 运行产生的本地结果。既有 ArkUI-X 平台结果作为历史证据保留；切换到微信小程序后，不再把它们作为当前客户端发布门禁。后续可点击原型截图、视觉 QA、微信三端真机、OCR/评分回归、安全和成本结果也应按版本写入此目录，运行产物默认不纳入版本库。

每类验证至少需要记录：

- harness 与场景版本；
- fixture 数据集版本；
- 被验证对象及其版本；
- 运行时间与环境；
- 逐场景结论、失败原因和验收核验记录；
- 评分或识别结果中的不确定性与已知限制。

平台执行器会将工作区和用户主目录替换为占位符，并对 `file://` 媒体 URI 做脱敏；报告仅记录是否显式提供设备 ID，不保存设备 ID 本身。

除本说明文件外，运行产物默认被 `.gitignore` 忽略；若未来需要提交基线结果，应先建立明确的版本和隐私策略。
