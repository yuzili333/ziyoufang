# 验证结果约定

此目录用于存放 harness 运行产生的本地结果。`client/scripts/platform-validation.mjs` 会在这里生成带时间戳的三端环境、构建或设备运行 JSON 证据；ArkTS、ArkUI、Android 和 iOS 限域验证脚本也会记录源码范围、诊断、产物哈希与明确排除项。运行产物默认不纳入版本库。

原型评审和技术选型完成后，应根据实际工具确定结果格式。至少需要记录：

- harness 与场景版本；
- fixture 数据集版本；
- 被验证对象及其版本；
- 运行时间与环境；
- 逐场景结论、失败原因和验收核验记录；
- 评分或识别结果中的不确定性与已知限制。

平台执行器会将工作区和用户主目录替换为占位符，并对 `file://` 媒体 URI 做脱敏；报告仅记录是否显式提供设备 ID，不保存设备 ID 本身。

除本说明文件外，运行产物默认被 `.gitignore` 忽略；若未来需要提交基线结果，应先建立明确的版本和隐私策略。
