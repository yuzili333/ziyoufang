# E03/E04 私有媒体交接基础验证

## 结论

- 日期：2026-08-11
- 状态：`verified-local-mocked`
- 范围：微信云私有文件从 BFF 到独立评测服务的短时访问授权、最小化传输、临时保存与有界下载。
- 结论：独立评测服务不再依赖无法读取的微信 `cloudFileId`。BFF 在文件归属校验后为每次开始/重试换取短时 HTTPS 访问授权，评测服务只在当前处理进程内使用，数据库、查询结果和遥测不保存访问 URL。当前使用模拟 HTTP 和云接口，尚未形成真实微信云环境证据。

## 安全与数据流

1. 小程序仍只把私有 `cloudFileId` 提交给 BFF，不接触临时下载地址。
2. BFF 校验主体路径和微信云文件状态后，换取最长 10 分钟的临时 HTTPS URL。
3. BFF 发往评测服务的任务采用字段白名单：任务/本地/幂等 ID、伪名主体、图片摘要、目标文字、结果版本、重评关系和临时媒体授权。
4. `cloudFileId`、私有上传路径、授权版本、上传票据等 BFF 内部字段不会跨服务传输。
5. 评测编排器只接受 HTTPS、无账号密码、未过期且剩余时间不超过 20 分钟的授权；授权保存在进程内一次性映射，不写评测任务仓库。
6. 处理完成、失败或取消后立即清除一次性授权；BFF 重试时重新换取授权，不复用已过期 URL。
7. 下载器要求精确主机白名单、禁止 HTTP 重定向、10 秒默认超时、15MB 流式上限，并在解码前核对任务 SHA-256。
8. 错误只返回稳定代码，不包含主机、路径、查询参数或临时令牌。

## 自动验证

- BFF 测试证明临时授权进入一次远端调用，但未进入 BFF 任务仓库；重试会生成第二份授权。
- 编排器测试证明 Provider 可以在一次处理期间读取授权，而仓库不含 URL、`cloudFileId`、上传路径或授权版本。
- 下载器测试覆盖正确摘要、过期授权、非白名单主机、摘要不符、响应头超限、无长度流式超限、超时和 302 重定向。
- 服务间既有 HMAC 请求体签名、时间窗和 Nonce 防重放继续覆盖包含临时授权的请求体。

## 尚未验证

- 微信云 `getTempFileURL` 在正式云环境中的 URL 主机、实际有效期、错误结构和三端上传对象兼容性。
- `MEDIA_DOWNLOAD_HOST_ALLOWLIST` 的生产配置、域名变更流程、DNS/出口策略及告警。
- 多实例部署下任务接收与处理必须位于同一工作单元，或将一次性授权迁移到加密、短 TTL 的共享能力存储；当前内存映射只适用于单进程基础验证。
- 真正网络下载的吞吐、并发、内存、超时和微信临时 URL 失效后的恢复仍需云环境与负载验收。
