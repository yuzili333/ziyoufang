# E09 可观测、安全与成本基础验证

## 结论

- 日期：2026-08-11
- 状态：`verified-local-synthetic`
- 范围：本地 Node 测试、合成 fixture 与内存存储。
- 结论：已经具备验证指标口径、安全边界和成本分项的工程基础；不等同于真实供应商、云环境或生产容量验证。

## 已验证能力

| 能力 | 实现与证据 | 结果 |
| --- | --- | --- |
| 遥测白名单 | `assessment-service/src/telemetry.mjs` 只接受固定事件/字段；敏感或未知字段测试 | 原图、路径、提示词、密钥、身份和完整结果不能写入事件 |
| 标识最小化 | 任务 ID 仅以独立密钥 HMAC-SHA256 后记录 | 事件和快照不含原始任务 ID |
| 时延与错误 | 编排器记录成功、失败、取消和安全错误码；快照按 Provider 调用计算 P50/P95 与错误率 | 生命周期事件不重复污染时延样本，Provider 异常落为可重试失败 |
| 成本拆分 | Provider 返回 `inputUnits`、`outputUnits`、`costMicros`、缓存命中；快照按 Provider 汇总 | fixture 成本固定为零，仅验证口径 |
| 指标访问保护 | `GET /internal/metrics` 复用 BFF HMAC、五分钟时间窗和 Nonce 防重放 | 无签名返回 401，重放返回 409 |
| 按主体配额 | BFF 使用版本化滑动窗口；幂等查询先于计数 | 重复请求不重复占用，超额返回重试时间 |
| 生产配置阻断 | 草案配额版本、未选择云事务分布式配额和缺失遥测哈希密钥在生产模式报错 | 未批准或不具备横向一致性的配置不能静默进入生产 |

## 未完成与门禁

- 当前事件缓冲仍为单进程内存实现；配额已具备云数据库事务 `quota_events` 的分布式实现，过期数据已具备每小时最多 100 条的幂等清理云函数。投产前仍须在真实云环境验证事务冲突、索引、定时触发、逻辑过期与私有文件物理删除，并接入持久指标后端。
- 尚未批准 P95、错误率、缓存命中率、单次成本和告警阈值；本轮只建立测量能力，不伪造业务目标。
- 腾讯云 OCR、混元或替代 Provider 尚未启用，因此不存在真实耗时、价格、准确率或限流证据。
- 尚未完成压力/容量、云环境、微信开发者工具与三端真机测试。
- 生产密钥必须由密钥管理服务注入，不得写入仓库或小程序。
